# AVDT : ce que c'est, qui est concerné, ce qu'il faut sur la carte grise

L'AVDT est l'attestation de vérification des données techniques. Elle s'applique à une voiture déjà immatriculée dans un pays de l'Union, dont la carte grise ne porte pas de numéro de réception par type (rubrique K). Elle coûte 67,38 €.

## Qui est concerné

Quatre conditions, toutes nécessaires :

1. Une voiture particulière (catégorie M1) ou un utilitaire léger (catégorie N1).
2. Un certificat d'immatriculation définitif et harmonisé d'un pays de l'Union : ni provisoire, ni d'export.
3. La rubrique K vide.
4. Les quinze rubriques ci-dessous renseignées.

## Les quinze rubriques

| Rubrique | Contenu |
| --- | --- |
| A | Numéro d'immatriculation |
| B | Date de première immatriculation |
| C.1 | Titulaire du certificat |
| D.1 | Marque |
| D.2 | Type, variante, version |
| D.3 | Dénomination commerciale |
| E | Numéro d'identification du véhicule (VIN) |
| F.1 | Masse en charge maximale techniquement admissible (kg) |
| G | Masse du véhicule en service (kg) |
| H | Période de validité |
| I | Date de l'immatriculation à laquelle se réfère le certificat |
| P.1 | Cylindrée (cm³) |
| P.2 | Puissance nette maximale (kW) |
| P.3 | Type de carburant ou source d'énergie |
| S.1 | Nombre de places assises, conducteur inclus |

## Ce qui fait rejeter la demande

- Une rubrique obligatoire manquante.
- Une donnée du certificat qui ne correspond pas au véhicule.

Dans les deux cas, la demande est rejetée et le véhicule passe en [réception à titre isolé](/homologation/rti/). La rubrique D.2 vide conduit directement à la RTI.

## Immatis

Immatis lit K et les quinze rubriques sur la carte grise déposée, et indique AVDT, RTI ou aucune voie. La catégorie M1/N1 et le caractère définitif du certificat ne sont pas vérifiés par l'outil.
